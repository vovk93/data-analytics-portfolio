## 2. Serbia Meteorological Dataset (1998–2024)

A structured meteorological dataset created from publicly available reports of the Republic Hydrometeorological Service of Serbia (RHMZ).

This project focuses on **data extraction, transformation, and structuring,** turning unstructured historical reports into a clean, analysis-ready dataset.

**Key features:**

- Long-term coverage (1998–2024)
- Meteorological variables (temperature, precipitation, and more)
- Cleaned and standardized format (Excel/CSV)
- Suitable for climate analysis, trend detection, and modeling

This dataset is publicly available on Zenodo and can be used for research, analysis, and educational purposes.
→ Dataset link: https://zenodo.org/records/19239744
→ See the */serbia-meteorological-dataset* folder for structure and details.
